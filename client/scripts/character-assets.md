# Авторские персонажи

Все формы созданы в репозитории средствами Three.js; сторонние модели/текстуры не использованы. Единица — метр, Y вверх, +Z вперёд, origin на земле между стопами.

Игрок и процедурные NPC: `src/render/three/CharacterRig.ts`, геометрии/материалы через `SceneAssets`. Иерархия: root → torso → head / shoulder → elbow; root → hip → knee → ankle. Длины сегментов ног по 0,38 м. Отдельные суставы каждого экземпляра, общие геометрии и материалы. `CharacterMotion.ts` задаёт темп, повороты, целевую траекторию стопы и аналитическое решение ноги. Полный цикл шага соответствует 1,2 м перемещения; стоящая стопа движется назад в локальных координатах с той же скоростью, что персонаж вперёд. Нет root motion. Визуальное состояние не записывается в Core.

Рынок и пастух: `generate-market-models.mjs`, функция `merchant`; экспорт в `public/assets/models/market/{market,pasture}.glb`. Редактируется генератор, не бинарник. Плечи привязаны к торсу; локти — к плечам; сосуд и обе удерживающие руки следуют одному торсу. Общий пятисекундный `idle` содержит дорожки отдельных именных групп с разными фазами; цикл замкнут. Статические поверхности объединены по группам с vertex colors, суставы остаются раздельными. Одинаковые итоговые геометрии и материал разделяются между группами при экспорте; это уменьшает GLB без связывания поз экземпляров. Детализация маленьких округлых деталей ниже, чем головы. Материалы матовые, без внешних текстур.

Из корня: `npm --prefix client run world:generate` пересобирает GLB и связанные размеры/хеши manifest. Повторный запуск должен сохранять идентичные бинарники. GLB загружаются только существующим AssetManager, с учётом источников и консервативного memory cap. В коде приложения нет второго загрузчика моделей.

Переходы клипов в `GltfLibrary` занимают 140 мс. Повтор имени сохраняет фазу; быстрый возврат к ещё активному клипу начинает смешивание из текущих весов. Неизвестное имя использует `idle`, когда такой клип есть. Динамический `walk` выбирается по наблюдаемому перемещению, а не только по сетевому имени состояния.

Ручная проверка: приблизить камеру колесом, пройти прямо, отпустить клавиши, быстро сменить W/A/S, упереться в стену, открыть меню и возобновить игру. На рынке проверить гончара и торговцев, на пастбище — пастуха. Точный контакт стоп на декоративной лестнице не подтверждён: её высота не участвует в текущей симуляции.
