# Эталоны аватаров

Неизменяемые входные данные для avatar-models.checks.mjs: хеши утверждённых GLB/геометрии и нейтральные transforms, а также исходные transforms/геометрия нижней части тела. Они перенесены из удалённого архива проверок без изменения проверяемых значений. Тесты читают эти фикстуры, но не генерируют и не обновляют их; новая версия требует отдельной осознанной проверки модели. Последнее переутверждение: 2026-11-08 (облики из Blender, равномерный масштаб); файлы пересозданы из текущих GLB, подробности — в [character-assets.md](../../character-assets.md).
