# SERVER-WORLD — Мир, чанки и область интереса

## Цель

Выдавать только необходимые игроку данные мира и поддерживать бюджет клиентского кеша.

## Требования

- **SERVER-WORLD-001:** Сервер хранит версионированные manifest, чанки и локальные GLB-ресурсы в формате [MAP](client-world-streaming.md); статические данные отделены от динамического состояния игроков и NPC.
- **SERVER-WORLD-002:** Область интереса определяется по авторитетной позиции игрока. Сервер разрешает HTTP-загрузку необходимых чанков и ресурсов, проверяет запрошенные идентификаторы и не выдаёт весь мир при входе. Допустимая область статической предзагрузки включает согласованный запас вокруг авторитетной позиции и не обязана совпадать с AOI динамических событий из REALTIME.
- **SERVER-WORLD-003:** Manifest предоставляет информацию для планирования загрузки и расчёта бюджета, не содержит полную геометрию. Версии/идентификаторы позволяют не использовать данные от другой версии карты.
- **SERVER-WORLD-004:** Для правила 10% сервер публикует согласованные общий объём мира и размеры ресурсов; метод расчёта совпадает с MAP. Общие ресурсы учитываются по единому правилу, бюджет не подменяется произвольным числом чанков.
- **SERVER-WORLD-005:** Повреждённый чанк, отсутствующая модель и неверный путь возвращают контролируемую ошибку; пользовательский ID не позволяет читать произвольные файлы сервера.

- **SERVER-WORLD-006:** Данные реального мира выдаются через проверку авторизации и допустимой области, включая прямые запросы GLB и связанных ресурсов; публичная статическая раздача не обходит эти проверки. Районы и переходы используют общий manifest/чанки и сохраняют идентичность мира и игрока.

## Сценарии

- **S1:** SERVER-WORLD-001–003: Given игрок меняет позицию; When запрашивает доступные чанки; Then получает нужные версии, а вне допустимой области запрос отклоняется или ограничивается.
- **S2:** SERVER-WORLD-004: Given manifest и набор ресурсов; When клиент рассчитывает бюджет; Then размеры воспроизводимы и согласованы с сервером.
- **S3:** SERVER-WORLD-005: Given неизвестный ID/путь; When отправлен запрос; Then посторонние файлы недоступны и сервер продолжает работать.

- **S4:** SERVER-WORLD-002, 006: Given известный прямой URL модели и соседний район; When запрос приходит без сессии или вне разрешённой области; Then доступ отклонён. When авторизованный игрок приближается к переходу; Then разрешена подгрузка согласованного соседнего набора без выдачи всего района.

## Ограничения и вне scope

Физический сервер не может гарантировать поведение произвольно изменённого клиента; ограничение кеша подтверждается штатной реализацией и её измерениями.

## Открытые вопросы

Согласовать метрику 10% из MAP, размер мира/чанка, радиус AOI, отдельный запас статической предзагрузки, поведение сервера при неготовых клиентских чанках и политику HTTP-cache. Без этого приёмка бюджета остаётся незавершённой.
