# Общий контракт и серверная симуляция движения

## Цель и изменения требований

Реализовать серверную часть новых MOVE-001–008, 012–014: контакт со стенами, вертикальную кинематику, спринт и выносливость. До кода закрыть открытые решения MOVE и согласовать изменения PROTO/SHARED/REALTIME/MAP/SERVER-WORLD; решения утверждены пользователем перед реализацией. Существующие требования сохраняют IDs и получают явно описанные изменения из раздела совместимости MOVE.

## Реализация

Согласовано пользователем: игровой Socket.IO v3 с совместной поставкой; `ceilingVolumes` (≤128 общих AABB и ≤128 на запись чанка), след 0,5×0,5 м, высота 1,8 м. NPC и HTTP BABEL сохраняют свои подконтракты. Точные правила зафиксированы в PROTO/SHARED до изменения кода.

## Результат

- `shared/movement/simulation.ts`: один профиль и чистые переходы опоры/прыжка/спринта/выносливости, расход только при перемещении, разделение шага истощения, задержка/блокировка, восстановление пересечения с диагностикой и запрет нового этажа на крыше.
- `shared/map`: swept-квадрат ±0,25 м проверяет всю площадь, AABB перекрытий проходят общий parser; данные по чанкам разделены на стыках. `GameMap` использует существующий индекс, проверяет безопасную опору/spawn.
- Игровой контракт v3 и fixtures строгие; прежние v1/v2 получают VERSION. Сервер и клиент требуют совместной поставки. NPC остаётся парой npc-question/npc-answer; BABEL HTTP сохраняет v2.
- `World`/`GameService`: authoritative motion в AOI, одноразовый jumpId/ACK, clear через jumpId=0, таймаут 250 мс, сохранение воздушной фазы/запаса при перехвате. После grace сохраняется краткоживущий долг выносливости; SQLite получает безопасную опору. Новая сущность после рестарта приземлена.
- `make server-test`: **131/131**, включая 17+ проверок кинематики, реальные HTTP/Socket.IO/SQLite, подготовленные перекрытия трёх карт и прежнюю лестницу. `npm --prefix server run check`: TypeScript shared/server и границы импортов проходят.
- Среда фактически Node **25.6.0**, macOS arm64. Путь `/opt/homebrew/opt/node@24/bin/node` также сообщает 25.6.0; запуск именно на закреплённом 24.15.0 здесь не подтверждён. Это ограничение среды, не доказательство проверки Node 24.
- Полная клиентская/аппаратная приёмка MOVE остаётся TASK-039. Подробности и ограничения: [evidence](evidence/movement/verification.md).
