## Завершение GLB/glTF

AssetManager в map владеет HTTP-байтами и ссылками, GltfLibrary в render — разобранными сценами/геометриями/текстурами. Shared AsyncLeaseCache объединяет активные загрузки, отменяет последнюю ссылку, удаляет ошибки для повтора и освобождает поздний результат после завершения. GLTFLoader получает только подготовленные локальные ресурсы; URL за пределами настроенного источника отклоняются. Декодеры с CDN не подключаются; исходные fixtures не сжаты Draco/KTX2.

GltfLibrary клонирует иерархии и скелеты через SkeletonUtils, использует независимые AnimationMixer для экземпляров и AnimationState для выбора клипа. После последнего владельца освобождаются общие GPU-ресурсы, ImageBitmap и ссылки на исходные данные. Клоны создаются максимум по 8 за кадр. VisualChunks поддерживает отдельные группы и отмену; EntityVisuals хранит динамические модели независимо от статических групп. В демо три экземпляра одной авторской анимированной таблички, включая независимую сущность.

Проверки 2026-10-31: `make client-test` — 93 теста в 10 файлах; `npm --prefix client run check` — 0 ошибок/предупреждений; `check:imports` — 45 модулей/107 зависимостей. `PLAYWRIGHT_CHANNEL=chrome npm --prefix client run test:browser` — 11/11, включая ошибку загрузки оформления и успешный повтор. После последнего владельца число GPU-геометрий и текстур возвращается к исходному.
