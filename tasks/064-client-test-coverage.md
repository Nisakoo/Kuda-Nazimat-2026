По запросу пользователя измерить процент покрытия, не подменяя его долей успешно выполненных тестов.

- [x] Настроить воспроизводимый V8-отчёт для всего исполняемого `client/src`: TypeScript и Svelte, включая не импортированные тестами файлы; исключить тесты и сгенерированные данные мира.
