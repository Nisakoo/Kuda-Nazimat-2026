# Диагностика падения FPS в high

## Цель и изменения требований

Проверить сообщение пользователя о 45 FPS вместо прежних 60 в обычной игре после серии ROPT. Требования не меняются. Текущий механизм кадров, FrameFence и фиксированный шаг симуляции сохраняются. Этап RDETAIL не начинается.

## Метрики до эксперимента

Сравнить HEAD до серии и текущий код в одинаковой обычной игре market с теми же текущими assets (включая пользовательский pasture.glb), high, radius 2, DPR 2. Отдельные CSS viewport 1280×800 и 1440×932. Браузер Chrome / M4; LocalSession с обычным UI не выдаётся за сервер/LLM. Исходники вариантов и размеры canvas записать. После ≥5 с прогрева краткие чередующиеся A/B пригодны для поиска причины; подтверждение исправления отделить от первичного скрининга.

Считать фактические fenceSync/отправки, rAF, интервалы, HUD CPU/P95/skips, ошибки и drawing buffer. Отдельно проверить вклад панели/графика/blur без изменения сцены и числа объектов. Различать shader/GPU стоимость, композицию DOM и нагрузку реального серверного окружения. Число FPS не подменять оценкой потенциального FPS.

## Результат

Низкий FPS воспроизведён и на исходном клиенте до ROPT: dev 44.9–52.8, production 49.1–52.4. Три production-пары дали current 49.0–51.1; медианы исходного/current 49.68/49.88 FPS, P95 34.3–34.8 ms. Это короткие диагностические сравнения, не новый performance acceptance; регрессия 60→45 от серии не доказана. GPU timer allocations в обычной игре — 0. Исходники 236/236 и assets 3573/3573 сверены.

Основной воспроизводимый фактор — готовность GPU при high DPR 2 / MSAA / shadow 2048. Скрытие графика/blur/всего UI не возвращает 60; снижение только 3D DPR до 1 или отключение теней во временной странице возвращает около 60. Повторение без GPU probe: DPR 2 34–40 FPS с 197–259 busy polls за ~600 циклов против DPR 1 58.7–59.1 с 9–13 busy polls. Точное историческое изменение пользовательского сеанса без идентичных браузера/окна/ракурса/фоновой нагрузки остаётся неизвестным; GPU duration не отождествляется с полной задержкой fence.

Новых runtime-изменений нет: профиль/FrameFence/симуляция сохранены, код не откатывался и качество не снижалось. Stage 3 остаётся принятой оценкой исходных теней; high не получил обещания ускорения. RDETAIL ещё не начат. Скрипты, raw/PNG, условия, результаты и ограничения — evidence (артефакт удалён).
