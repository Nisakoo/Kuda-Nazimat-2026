`correction-supplement-results.json`: keyboard/radio/Enter выбора облика пройдены; logout204. Затем через настоящие Settings выбран `local`, карта `market`, без изменения radius/debug. Actual `correction-supplement/failure.png` показывает «Не удалось загрузить участок мира».

Это не основание обвинять GPU или исправление фокуса. `GameApp.worldRoot()` для local использует origin `/`. Read-only GET `/maps/market/manifest.json` и `/maps/demo/manifest.json` на4387 вернул404; receipt `correction-local-host-readback.json` датирован **2026-11-01T05:16:31.577Z**. `server/src/http/server.ts:169` намеренно запрещает public `/maps` и `/assets/models`; online использует авторизованный `/world`. Нельзя обходить этот запрет или превращать локальный режим в доказательство server acceptance.

**Решение:** local `Ваша сумка` / первый и второй I фактически не упражнены. Не считаются pass. Не заявляю новую UI-регрессию без поддерживаемого local-host baseline. Требуется согласовать отдельный read-only local frontend host либо явно оставить этот сценарий непроверенным. В рамках freeze я другой сервер не запускал.
