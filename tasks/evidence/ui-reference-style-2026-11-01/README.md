# Проверка оформления существующего UI

Результат [TASK-065](../../065-ui-reference-style.md). Состав и поведение экранов сохранены по последнему уточнению пользователя. Основные действия — тёмная бирюза, второстепенные — пергамент с песочным контуром; скошенные углы, мятное выделение, прозрачные иконки и подчёркнутые вкладки. Встроенные слова сохраняют оформление текста. Никакие отсутствовавшие кнопки не добавлены.
