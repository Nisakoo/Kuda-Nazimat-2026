## Что реализовано
- Парольные register/login, явный отдельный demo guest, bounded scrypt/попытки/crypto concurrency, закрытый session response, память клиента без токена/пароля в localStorage.
- Server revoke/logout, закрытие только транспорта matching token, отмена NPC/BABEL без commit; server full до регистрации/выдачи новой сессии; takeover существующего места сохраняется.
- Durable first-avatar marker: password credential + NULL avatar. До подтверждения нет game join. При следующем входе выбор возобновляется. Старые guest не переименованы в регистрации.
- 4 локальных исходных GLB, закрытый ID, native выбор 2×2/постамент/вращение/портреты из реальных моделей. Смена только после server save; live AOI update. Preview имеет declared byte/memory sizes и общий 64 MiB guard с уже загруженным миром. Портреты снимаются последовательно; одновременно удерживается только 1 GLB, а не все 4. Rapid selection сериализуется, старый lease освобождается до нового.
- Сохранённый игрок тоже проходит режим/языки перед транспортом. Его существующий режим/партия/прогресс не сбрасываются: mode подтверждается, меняется только пара языков, повторный enroll не отправляется.
- HUD/dock, 1 native окно, I inventory, Esc/крестик/repeated dock, явный resume Pointer Lock. За окнами продолжаются авторитетные сетевые обновления, движение остановлено.
- 1 server equipment slot bag/jug/null, projection настоящих BABEL counts, live предмет у кисти и видимость другим клиентам. Transfer/capacity/NEXT pickup не добавлены.
- Приватные learned/note/examples с legacy JSON defaults. «Запомнил» сохраняет отредактированную заметку/пример до переноса. Чат/перевод/статусы/камни сохранены.
- Серверные taskTitle/taskTarget/partyPositions. Только текущие task members, включая peers вне загруженного AOI; никаких произвольных игроков. Более свежие AOI данные имеют приоритет. Map авторская изометрическая схема реальных footprint, не вымышленный фонтан.
- Оригинальные объёмные entry PNG, воспроизводимо baked из локальной Three.js scenery без нарисованных контролов; прежние SVG сохранены как история. Stone panels и реальные region transitions остаются в UI, footer не создаёт ложные игровые данные.
- Синхронизация dictionary note/example/translation использует primitive выбранного ID для защиты draft. Однако correction reviewer подтвердил R-09/P2: именно chat-seeded ручной перевод после suggest сам стирается. Общий тезис о полной защите draft не принят; см. correction-r09-seed-draft.md.
- Enter из mode radio продолжает к языкам; Escape возвращает к сохранённому выбору. Desktop login использует compact layout также при высоте800, без уменьшения 44px целей.
- У карты сохранён непрозрачный paper background под corner decorations. Start/Resume ждут существующий visualLoading (реальные pending/queued models), но не deferred chunks или GPU completion; захват остаётся явным.
