## Исправленные дефекты и отрицательные регрессии

1. Regular game delta перед volatile scene подавлял scene при непрерывном MOVE. Теперь изменившиеся scene revisions идут надёжно до delta, время — ограниченным heartbeat. Полный неизменный definition не парсится для каждого seat/тика.
2. Первый rising-шаг jump (`dt=0,001`, Y=0,005394) позволял положить яблоко. Теперь требуется authoritative grounded; тест покрывает близость к земле, не только Y=1.
3. Удаление целого worldLife-каталога могло скрыть сохранённые яблоки. Инициализация сверяет полный набор сохранённых IDs/maps с ожидаемым; неожиданные данные дают ошибку, не тихое исчезновение.
4. MOVE наполнял вечный Set request IDs до rate-limit. Движение дедуплицируется sequence, прочие connection IDs ограничены. Общий outbound cap включает game и life; медленный настоящий polling-клиент закрывается, revision-dependent delta не выбрасываются молча.
5. Критический захват ввода вызывается до синхронного создания необязательного AudioContext; оба запроса остаются в одном trusted handler. Unit проверяет строгий порядок `capture → audio`. Это не объявлено исправлением причины slow native capture. Локальные goat controls больше не создают ложную реплику; подготовленные локальные NPC greetings и реальные question/answer сохранены. BABEL interaction уже был тихим, это дополнительно проверено для old history/reopen/goats.
6. Аудио: освобождены слоты ушедших игроков; тихие baselines обрабатываются до live; pending chat не считается уже показанной историей; chat IDs включают автора; вопрос/ответ имеют разные устойчивые IDs; cooldown не поглощает вторую отдельную реплику одного poll. Холодный batch ограничен 8 свежими событиями с первоначальным deadline 250 ms, без продления replay.

159 server tests включают 4 реальные BABEL-роли, гонки, один слот, changed-payload retry, lost reply after commit, повторные SQLite reopen, upgrade v2 с accounts/positions/history, rollback, auth/control, дальнюю модель переносимого яблока, стены/зоны/edge/occupied/air, RAM pots/reset footprints и неизменность BABEL inventory. Client tests включают F edge/reset, неoptimistic hands, stale/timeout/reconnect, runtime fixtures и явный mock без fallback, rig/каталог/ветер/resources, volume/autoplay/ошибки/dedup/dispose.
