# Игровой HUD без кнопок

Последнее уточнение пользователя отменяет инвентарь целиком, включая три ячейки. Взятие одного предмета в руки реализуется в другой ветке; перенос этой реализации в задачу не входит.

- [x] Убрать из игрового HUD нижнюю панель, инвентарь, кнопки задач, языка, настроек, меню и взаимодействия. Оставить текст текущего задания и языка; окна со свободным курсором сохраняют действия и формы.
- [x] Tab открывает задачи из игры; 1 — чат, 2 — словарь, 3 — карта, 4 — языки; Esc открывает меню. Старые I/M/K/Enter/J/L/O больше не открывают окна.
- [x] Удержание Alt/Option показывает справа снизу подсказку управления; отпускание, потеря фокуса/захвата, открытие окна убирают её. AltGr и ввод текста не вызывают подсказку.
- [x] Сохранить обычный Tab в модальных окнах и ввод цифр в формах, отмену NPC при смене окна, блокировку движения и явное возвращение управления.
- [x] Обновить затронутые браузерные сценарии, выполнить клиентские тесты, типы, импорты, сборку и браузерную проверку. Записать результаты.

## Результат

Реализованы физические Tab/1–4, убраны старые I/M/K/Enter/J/L/O и все кнопки игрового HUD, включая инвентарь. В открытых окнах сохраняются формы и действия со свободным курсором. Язык отображается текстом, меняется через окно 4. Tab в окне перемещает фокус. Alt/Option показывает краткое управление; оба Alt учитываются вместе, blur/остановка/потеря захвата сбрасывают подсказку.

Промежуточная проверка: 314 клиентских тестов, Svelte/TS без ошибок и предупреждений, импорты без нарушений, сборка успешна (существующее предупреждение >500 kB). Первый браузерный прогон: 19/21, новый сценарий управления прошёл. Отказы: маршрут теста упирался в край прилавка x=-2.1, а переименованный помощник сохранённого предмета затенялся локальной переменной теста. Исправлены маршрут к доступной точке взаимодействия и имя переменной; серверное подтверждение предмета осталось в сценарии. [Промежуточный лог](evidence/keyboard-hud-2026-11-01/browser-initial.log).

Итоговая проверка объединена с TASK-059: **22/22** браузерных сценария на реальном сервере прошли за 2.3 минуты ([лог](evidence/replace-game-2026-11-01/browser-final.log)). Новый сценарий проверяет отсутствие кнопок/инвентаря, старых сочетаний и подсказок без Alt; открытие задач на Tab, обычный Tab в окнах, 1–4, набор цифр в чате, сохранение языка, Esc/настройки и сброс Alt при blur. Визуально проверены [HUD](evidence/replace-game-2026-11-01/keyboard-hud-1280.png) и [подсказка 390 px](evidence/replace-game-2026-11-01/controls-alt-390.png).

Финальные [314 клиентских тестов](evidence/replace-game-2026-11-01/client-tests.log), [типы/Svelte](evidence/replace-game-2026-11-01/client-check.log), [импорты](evidence/replace-game-2026-11-01/imports.log) и [сборка](evidence/replace-game-2026-11-01/build.log) прошли. Физическая LAN/LLM и перенос механики одного предмета из другой ветки не входят в эту проверку. TASK-053 остаётся в очереди.
