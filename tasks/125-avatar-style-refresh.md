# Облики игроков в стиле референса экрана выбора

## Цель

Приблизить четыре облика к референсу экрана «Выберите свой облик»: крупная мягкая чиби-голова, гладкое лицо, светлая тёплая кожа, маленький нос, объёмные волосы с прядями. Требования AVATAR-009/010 не меняются; игровые размеры, анимации, контакт стоп и ширина/глубина сохраняются.

## Изменения в `client/scripts/generate-avatar-models.mjs`

- [x] Голова — гладкий эллипсоид (`headShell`, `HEAD`, `headZ`) с сужающимся подбородком и мягко уплощённым лицом. Группа головы масштабируется только по ширине и высоте (1,08 × 1,2 × 1), поэтому общая глубина 0,56 м, масштаб Z, темп шага и контакт стоп прежние.
- [x] Черты лица проецируются на поверхность головы: крупные глаза с двумя бликами, тонкие брови, румянец, улыбка, ресницы Ксю, очки с дужками до ушей.
- [x] Острый клиновидный нос заменён маленькой мягкой «кнопкой».
- [x] Кожа светлее и теплее (`SKIN #f7bc93`, `SKIN_SHADE #eba47d`, `BLUSH #f29482`); гладкие кожаные детали без цветового шума граней.
- [x] Волосы: плоские пряди-пучки по поверхности скальпа (`tuft`, `crownTuft`) с гладкими нормалями, три тона на причёску. Короткие/взъерошенные/зачёсанные стили — венец из 13–15 прядей; у Ксю пряди расходятся от пробора, передние пряди обрамляют лицо, а не закрывают щёки.
- [x] Одежда сверена с референсом: туника с V-вырезом, пояс с концом, светлые штаны, коричневые ботинки уже совпадают — без изменений.

## Эталоны

Эталоны в `client/scripts/fixtures/avatars/` осознанно переутверждены для новой скульптуры:

- `approved-neutral.json` — хеши GLB/геометрии и нейтральные transforms (изменились голова, волосы, лицо, масштаб `avatar` по Y).
- `lower-body.json` — `avatarScale[1]` (тело ниже на 9–10% из-за крупной головы; X/Z проверены как неизменные) и хеши `knee-*-surface`: позиции, нормали и индексы голени побайтно совпадают со старыми, изменился только цвет вершин кожи. Transforms ног не изменились.
