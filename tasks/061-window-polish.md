# Закрытие окон, выравнивание действий и выносливость

- [x] Отделить открытие паузы от технической остановки управления. Закрытие окна HUD не открывает паузу; Esc открывает её только при отсутствии другого окна. Настройки, открытые из паузы, возвращаются в неё.
- [x] Закрытие игрового окна возвращает управление; при отказе браузера в Pointer Lock доступно отдельное восстановление без открытия паузы. Ввод очищается, скрытое окно не перехватывает фокус.
- [x] Выровнять действия и поля окон чата, словаря, языка, задач, карты, настроек и паузы: одинаковые высоты, устойчивое размещение, перенос/прокрутка на небольших экранах; hover не меняет геометрию.
- [x] Перенести выносливость вправо вниз, оформить светлой карточкой с бирюзовым кольцом, числом и читаемым восстановлением. Alt-подсказка не перекрывает индикатор.
- [x] Client tests, типы/импорты, production build, браузерные регрессии закрытия и снимки окон/выносливости; записать результаты.

## Результат

Введено отдельное состояние `pauseOpen`: остановка управления для окна больше не создаёт паузу. Закрытие HUD запрашивает возврат управления, повторный Esc закрывает паузу; настройки сохраняют возврат в явно открытую паузу. При отказе Pointer Lock есть компактное восстановление и выход в кабинет. Быстрый повтор Esc может временно блокировать повторный захват в Chrome; браузерный тест проверяет отдельный повтор после этого отказа, без возврата паузы.

Общие стили окон выравнивают поля, кнопки и панели действий; «Закрыть» вынесена за прокручиваемый контент, словарь/чат перестраиваются на узком экране. У выбора персонажа нижние кнопки занимают равные колонки. Выносливость справа снизу: светлая карточка, песочная дорожка, бирюзовая дуга, процент; восстановление обозначено текстом. При Alt-подсказке карточка скрыта.
