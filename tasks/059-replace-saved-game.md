## Результат

`create` принимает необязательный `replacePartyId`: сервер сверяет его с текущей собственной группой и выполняет создание, смену профиля, выход из старой группы и удаление пустой группы в одной SQLite-транзакции вместе с квитанцией requestId. Профиль, облик и словарь сохраняются. Участники старой группы и их данные остаются; роль нового участника выбирается из свободных. Повтор подтверждённого запроса не удаляет новую игру. Поздний ответ NPC из прежней группы не записывается в новый профиль.

Клиент показывает отдельное подтверждение выбранного режима; исходный фокус на «Отмена», Esc отменяет только подтверждение. «Продолжить игру» остаётся доступным. ID группы и режим фиксируются при открытии подтверждения, чтобы обновления профиля не меняли согласованное действие. Чужая ожидающая группа сохраняет прежнее ограничение создания: её нельзя удалять от имени другого игрока, можно присоединиться.
