# Серверные игровые механики Вавилона

## Цель и изменения требований

Полная серверная часть BABEL в согласованных границах: группы 1–4, языки, перевод, приватные NPC, камни, минимальное задание рынка, инвентарь и личный словарь. Согласованные решения записаны в BABEL. Клиентская интеграция выполняется отдельной задачей. Декоративное расширение рынка NEXT-006 не входит автоматически в BABEL.

## Реализация

- [x] Общий строгий контракт BABEL v2 и защищённый транспорт, совместимый с существующим движением v1.
- [x] SQLite-профили, группы, роли, инвентарь, история, словарь и идемпотентность.
- [x] Серверная проверка расстояния, роли, покупки и кормления; переводы заданий ru/en/es.
- [x] Общая очередь для перевода/NPC/подсказки словаря, явный тестовый backend и порт для реального локального адаптера. По уточнению пользователя Ollama выполняет другой исполнитель; адаптер не входит в эту задачу.
- [x] Тесты прав, ошибок, повторов, смены языка, рестарта и серверного сценария рынка.

## Приёмка

- [x] BABEL S1, S3–S8: серверные сценарии с настоящей SQLite и авторизацией проходят.
- [x] Сетевые/языковые ошибки не создают фиктивного успеха или предметов.
- [x] `make server-test`, типы и границы импорта проходят.
Реальная LLM (качество языковых пар, задержки и RAM) остаётся внешней приёмкой BABEL/LLM-QA, не результатом тестового backend. Общая очередь и квоты проверяются здесь.

## Результат

Реализованы строгий shared-контракт, HTTP с авторизацией/проверкой управляющей сессии, SQLite-агрегаты и атомарные receipts, роли и сохранение позиции, инвентарь/кормление, неизменяемые камни, личный словарь и NPC-история. SHA-256 fingerprint не удерживает исходный текст удалённой записи. Переводы фиксируют языки при принятии запроса и не подменяются исходником при ошибке. На карте market старая Socket.IO-доставка чата/NPC для участников BABEL закрыта; на прежних картах чат и NPC продолжают работать.

Проверки 2026-10-31: `make server-test` — 87/87 в 13 файлах; `npm --prefix server run check` — типы server/shared, импортные границы без нарушений (54 модуля / 155 зависимостей). Отдельной команды server check:imports нет: эта проверка уже входит в check; ошибочный дополнительный вызов не считается проверкой.

`babylon.test.ts`: режимы/роли, дистанция, четыре кормления, сохранение/retry, язык на момент принятия, приватность, 64 слова, 8 камней, откат при SQLite-ошибке, общий FIFO четырёх игроков и запрет пятой generation. `integration.test.ts`: реальные HTTP/Socket.IO, отсутствие auth, подмена владельца, takeover во время перевода, запрет старого чата и повтор без дублирования камня.
