# Клиентское движение, круг выносливости и анимации

Подключить согласованный контракт MOVE к LocalSession/OnlineSession, добавить Space/Shift, круговой HUD и фазы анимации. Реализуются новые MOVE-001–014 в клиентской части; приёмка охватывает настоящий сервер. До реализации согласовать изменения UI/CORE/NET/RENDER и общий контракт из серверной задачи; критерии CHAR остаются базой визуального качества.

## Результат

Код LocalSession/OnlineSession, ввода, HUD и процедурных поз реализован. Прежнее застревание воспроизведено до исправления headless-тестами: локальный диагональный шаг полностью отменялся; онлайн guard отправлял нулевое направление при готовой касательной. После исправления оба регрессионных теста проходят. Браузерной записи исходной ошибки в конкретном месте карты до изменений нет, поэтому первый пункт реализации остаётся незакрытым.

- LocalSession и сервер используют `shared/movement`; локальный тест сравнивает все позиции/состояния с чистой симуляцией при одинаковых dt/вводе; серверный тест делает то же со стороны World.
- Physical Space/оба Shift, короткое нажатие между input, монотонные jumpId без повторного использования при clear, очистка и reconnect покрыты тестами. Состояние motion копируется/замораживается EntityManager.
- Данные перекрытий извлечены из GLB до batching. Плоские меши получают 1 мм толщины; containment/объединение без заполнения промежутков сокращает объёмы до лимита. Коллизионная ширина перил лестницы учитывает навершия, поэтому движение вдоль них не цепляется за выступы. Manifest учитывается существующим бюджетом.
- Кольцо 56/6 CSS px, процент, named progressbar, светлая/янтарная дуга и текст восстановления. Переход 80 мс; ноль/блокировка немедленны. Увеличен отступ до footer; узкий HUD перераскладывается.
- Игроки используют процедурные спринт/отталкивание/подъём/падение/амортизацию; NPC не получают новые способности. Переходы 140/100/140 мс, источник — подтверждённая фаза/реальное движение. Unit-тесты при 30/60 FPS проверяют первый отклик, прерывание новым прыжком и отсутствие ложного приземления при коррекции.
- `make client-test`: **184/184** после добавления двух проверок поз; `check`, `check:imports`, `build` проходят. Сервер: **131/131** и `check` проходят в фактической среде Node 25.6.0.
- Полный Chrome production-прогон: **43/43**. После последних изменений повторены движение/HUD, лестница, layout и реальный сервер: **19/19**. Render: **8/8**, четыре записи собственного/остальных визуалов спереди/сбоку при шагах 30/60 FPS. Профили demo/market (5+60 с, пять перезапусков) записаны отдельно.
- [Доказательства и ограничения](evidence/movement/verification.md). Все обязательные критерии пока не закрыты: четыре физических LAN-клиента, физическое отключение интернета/Wi-Fi, настоящий browser zoom 200%, полный численный разбор визуальных переходов/опоры стоп и исходная браузерная запись. CSS viewport, MediaRecorder и виртуальные часы не выдаются за эти проверки. На закреплённом Node 24.15.0 эта сессия не проверялась.
