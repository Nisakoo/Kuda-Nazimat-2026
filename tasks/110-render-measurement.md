# Воспроизводимый baseline рендера

## Цель и изменения требований

Первый этап ROPT: измерить текущую стоимость рендера до выбора оптимизаций. Требования не меняются. Последующие этапы не начинаются до принятия результата RPERF.

## План и метрики до эксперимента

- Условия: market, радиус 2, CSS 1280×800, device DPR 2; low/balanced/high отдельно; установленный Chrome, Apple M4 / 16 GB, macOS 26.3. Фактический backend, питание и buffer записывает evidence.
- Изолированный renderer использует реальные manifest/GLB, ChunkManager и WorldBudget; синтетические позиции и фиксированное время сцены помечаются явно. Он не подтверждает симуляцию, LAN, LLM или аппаратный профиль слабого ноутбука.
- По три последовательных прогона на профиль: ≥5 с прогрева, ≥60 с записи; маршрут и контрольные кадры задаются в harness. Холодная загрузка и пять входов/выходов отдельно.
- Целевые метрики этого этапа: CPU по фазам, draw calls (включая тени), triangles, GPU duration при доступном расширении, P95/P99 отправок, submitted/skipped, загрузочные пики, ресурсы/heap после GC. A/A не считается ускорением.
- Диагностика включается явно; её стоимость оценивается на том же маршруте с выключенным сбором. Для будущих кандидатов: ≥10% целевой медианы и больше разброса, P95 не хуже 5%.

## Результат

Исходный commit и локальный diff сохранены в `evidence/render-measurement/input-commit.txt` и `input.patch`. До начала работы изменён только `client/public/assets/models/market/pasture.glb`; содержимое пользователя сохраняется. Новые оптимизации пока не приняты.

Подробные условия, raw JSON, повторы/GC, визуальные кадры, команды и ограничения — evidence (артефакт удалён). 478 unit-тестов, check/imports/build, 15 WebGL и 2 браузерных сценария прошли. Четыре реальных авторизованных Chrome-клиента на HTTPS/WSS прошли три записи по 60 с против временной SQLite (test LLM, loopback). Три пары off/on не выявили различимого роста CPU-медианы; худшее изменение P95 кадра +0,6%.

Продлённая серия low/high выполнена: ещё три ≥60 с записи каждого профиля; raw, медианы и разброс в `repeat-*`. Внутри последней high GPU-размах 2,1%, low — 9,7% относительно средней медианы. Межсерийный дрейф сохраняется, его причина не установлена. Baseline принят для M4 с обязательным чередованием будущих A/B в одной серии; рост FPS между неизменёнными сериями не называется ускорением. Архив принятых исходников — `baseline-source.tar.gz`. Слабый ноутбук/физический LAN/MLX/Ollama не квалифицированы. Ошибочная первая CPU-overhead серия изолирована и не используется. RBATCH теперь может начинаться отдельной зависимой задачей.

Артефакты проверок удалены по запросу пользователя; исторические результаты и команды выше сохранены. Новые материалы проверок хранятся вне checkout (TASK-119).
