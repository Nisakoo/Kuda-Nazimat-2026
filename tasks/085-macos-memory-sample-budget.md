# Ограниченный бюджет замера памяти на macOS

## Основание и граница

Пользователь сообщил об успешном английском ответе по теме; безопасный фрагмент лога показывает завершение за 27,469 с. Следующий запрос отказал с `memory_sample_ps_timeout`; затем отказало восстановление с тем же кодом. Это подтверждает отказ измерения, но не устанавливает причину задержки ОС и не доказывает превышение RAM. Идентификаторы пользователя/сессии и тексты запросов в evidence не копируются.

Для macOS бюджет команды измерения RSS меняется с 500 на 1500 мс, общий deadline измерения с 600 на 1600 мс. Это ограниченный кандидат против задержки команды под нагрузкой, а не доказанное исправление на Mac. Увеличивается возможное окно без нового замера; профиль по-прежнему не квалифицирован по пику RAM. Linux остаётся 500/600 мс. Порог 3 500 000 000 байт, предел 4 GB, период после замера 250 мс, полный охват процессов, отказ при неизвестном результате и отсутствие кеша/повторов сохраняются. Проверка живости при cleanup по-прежнему использует прежние 500 мс; escalation/quarantine не меняются. Таймаут игрового вопроса и BABEL HTTP 30 с не увеличиваются.
