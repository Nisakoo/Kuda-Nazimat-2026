# Пауза, настройки и помощь

## Цель и границы

Реализовать полный client-pause-menu.md и связанный вход в настройки после текущего упрощения HUD. В main опубликована самостоятельная client-settings.md; учесть её при реализации. TASK-061 отдельно исправляет переходы паузы и верстку существующих окон, но не реализует все новые разделы настроек и Помощь.

## Реализация

- [x] Согласовать PAUSE с текущим кабинетом HUB: выход из мира возвращает кабинет; не восстанавливать удалённый этап языков.
- [x] Учесть последнее требование о простом оформлении без логотипа и декоративных углов.
- [x] Пауза открывается только по Esc; верхней кнопки и нижней панели нет согласно уточнению HUD-003–004. Затемнение/размытие мира.
- [x] Существующие действия паузы сохранены; добавлена Помощь, Tab/Enter/Esc и восстановление управления. PAUSE приведён к согласованному поведению, новые обязательные стрелки не вводятся.
- [ ] Настройки и выбор облика с возвратом в паузу; содержимое новых настроек определить по отдельной спеке, когда она появится.
- [x] Сохранены существующие выход в кабинет и отзыв сессии без нового подтверждения; закрытие потокового диалога отменяет запрос. Решение следует приоритету текущего кода, заданному пользователем.
- [x] Помощь на родном языке и таблица актуальных клавиш HUD-007 (Tab, 1–4, Esc), согласованная с краткой подсказкой Alt/Option из TASK-058.

- [ ] Проверка узких экранов и клавиатуры, возврата из настроек/облика/помощи и сохранений после выхода.
