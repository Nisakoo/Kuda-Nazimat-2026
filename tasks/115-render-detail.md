# Дальний мир и пространственные ветви

## Цель и изменения требований

Четвёртый этап ROPT; требования не меняются. Сохранить все игровые объекты, радиус и коллизии. Проверить геометрическую детализацию и более дешёвую подготовку дальнего мира, принять только подтверждённый результат.

## Метрики до кода

Market / radius 2 / CSS 1280×800 / device DPR 2, три профиля, маршрут RPERF, M4/Chrome. Baseline — TASK-113; текущие исходники и assets сохранены TASK-114. High использует legacy marks.

- Дальний ветер: использовать существующий абсолютный timeMs и интервал 100 ms за 48 m (у low/balanced уже есть); цель CPU chunks median ≥10% и выше разброса. Возврат ближе обновляет текущую фазу сразу. Проверить плавное приближение/поворот, тени и руки; никакой частоты симуляции не меняется.
- Spatial branches: максимум 25 root bounds, резерв 64 KiB до создания; объединение main и shadow frustum, текущие world transforms. Ветви исключаются только на время renderer.render и восстанавливаются в finally; неопределённость оставляет видимость. Цель CPU submission median ≥10% с учётом стоимости bounds.
- После короткого screening вариант branches уточняется повторным использованием уже рассчитанных CameraRaycast bounds (cached-branches). Полный A/B уточнённого варианта ещё не выполнялся. Нужен fallback первого лица/неподготовленных/неполных bounds; исключённые из raycast декоративные batches учитываются исходными поверхностями с консервативным запасом для следов.
- Простой геометрический LOD: определить измеренно дорогие геометрии и допустимую экранную ошибку ≤1 CSS px; пороги/гистерезис фиксировать до прототипа, если найдены подходящие отдельные декоративные модели. Не упрощать целую архитектуру с игровыми ориентирами без проверки силуэта. HLOD/impostor только после необходимости простого LOD.
- Для прошедших контроль качества кандидатов — три чередующиеся ≥60 s пары после ≥5 s прогрева. P95 интервалов не хуже 5%; GPU/calls/triangles/память записываются отдельно. Быстрый screening не считается приёмкой.

Эффект не выше разброса; P95 не ухудшен, но внедрение по RPERF-005 не принимается. Простое whole-mesh subpixel culling не имеет объектов на выбранном пороге 1 CSS px; новый геометрический LOD/HLOD не заявлен.

Кандидаты изолированы в e2e, high сохраняет исходный ветер; коллизии/профили/FrameFence не менялись. Качество и fallback проверены во всех профилях на пяти ракурсах, high с видео движения. Все 20 завершённых high lifecycle cycles полной/дополнительной серии освобождают WorldBudget и targets; retained heap ниже прогретого baseline.
