# Крепления сушащейся ткани у красильни

## Причина
На пользовательском снимке три полотнища выглядят как летающие квадраты: генератор задавал только цветные прямоугольники на высоте, без несущей конструкции. Исправляется представление существующих объектов; новые игровые требования не вводятся.

## Реализация и приёмка
- [x] Добавить деревянные стойки, перекладину, крепления и складки; сохранять всю конструкцию вместе при размещении.
- [x] Коллизии стоек соответствуют геометрии; доступность жителей и интерактивных предметов сохраняется.
- [x] Генерация, клиентские тесты, сборка и целевая проверка реального мира пройдены. Новые снимки не делаются.


## Результат
Три полотнища теперь висят на деревянных сушильных рамах: шесть стоек, перекладины с подкосами, семь подвесов на каждую ткань, двусторонние складки и кромка. Рама с полотном — единая композиция для fitDistrict, поэтому крепления не отделяются при переносе. Коллизии опор узкие; сохранены исходные цвет, высота и район размещения. Обновлены city-dye.glb и генерируемые контуры карты.
