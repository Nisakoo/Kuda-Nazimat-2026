# Стоимость кадра на слабых ноутбуках: мусор в кадре, HUD, склейка статики, автопрофиль

## Цель и изменения требований

По поручению пользователя (ветка `perf/client-optimization`) выполнить два направления аудита клиента: быстрые правки без изменения вида (аллокации и обходы в кадре, частота HUD, дальность камеры, лучи камеры, blur) и склейку статических мешей потоковых моделей с автоматическим выбором профиля графики. Все прежние замеры ROPT сделаны только на M4; на слабом железе узкие места — draw calls, GC-паузы и перерисовка UI.

Изменено **RENDER-009**: профиль по умолчанию подбирается по устройству, пока игрок не выбрал его сам (high автоматически не выбирается, подобранное значение не сохраняется); облегчённый профиль сокращает дальность тумана до 60 м; геометрия за непрозрачным туманом не рисуется. Добавлен сценарий S9.

## Реализация

- [x] Аллокации в кадре: `WorldLifeVisuals` строит индексы состояния один раз на сообщение; кэш именованных узлов (`namedNode`) вместо `getObjectByName` в кадре (птицы, кошки, вьючные животные, привод мельницы, руки, дробовик); `VisualChunks` хранит стабильные `readyIds` и список корней для камеры; `getDiagnostics()` материализует списки лениво, ошибки кэшируются; `syncWorld` пропускает повторную ту же пару снимков (онлайн-презентация каждый кадр); строки диагностики строятся только для debug или при патче.
- [x] HUD: кольцо выносливости патчит снимок приложения не чаще раза в 6 шагов (~10 Гц); появление, блокировка, пустое/полное значение — сразу. Маркер карты не троттлится: карта останавливает игру и следует только авторитетным дельтам.
- [x] Камера: дальняя плоскость = дальность тумана + 5 м (120 → 85 м; low 65 м). Лучи препятствий не пересчитываются, пока камера, цель и набор чанков не изменились; неподвижная камера перепроверяет каждые 10 кадров.
- [x] `backdrop-filter` у `.glass` выключен поверх живого canvas (`.game-screen .glass`), фон почти непрозрачный.
- [x] Автопрофиль: `recommendGraphicsQuality` по `WEBGL_debug_renderer_info` (Intel, кроме Arc; AMD APU; Mali/Adreno/PowerVR; SwiftShader/llvmpipe/Basic Render), `hardwareConcurrency ≤4`, `deviceMemory ≤4`. Временный контекст сразу освобождается (`WEBGL_lose_context`).
- [x] Склейка статики: `mergeStaticMeshes` один раз на шаблон GltfLibrary для потоковых моделей (путь `staticTransforms`), после настройки теней. Группа = якорь (ближайший анимированный узел или корень) + материал + cast/receive shadow + layers + формат вершин. Отдельными остаются узлы `wind-*`, `babel-symbols`, анимированные, скрытые, зеркальные, с детьми, морфами, группами или drawRange. Под анимированным узлом меши склеиваются в его локальных координатах, поэтому клипы продолжают их двигать. Склеенная геометрия общая для всех экземпляров и освобождается с шаблоном.

Отклонение от исходного предложения: склейка выполняется при подготовке шаблона в клиенте, а не в генераторах. Генераторы и GLB не меняются, именованные узлы для анимаций/ветра/символов сохраняются; стоимость — одна склейка на модель при первой загрузке. Запекание света в вершинные цвета не делалось: это меняет вид и требует визуальной приёмки; облегчённый профиль и так без теней.
