# Клиентская интеграция Вавилона

## Цель

Подключить существующий клиент к серверным механикам BABEL: вход, режим, языки, информационное окно, задания/инвентарь, перевод, камни, словарь. Клиент отправляет намерения и показывает подтверждённые результаты. Локальный стенд сохраняется отдельно. Новый дизайн экранов из других веток не входит в задачу.

## Реализация и приёмка

- [x] Вход и смена языка, сохранённые серверные состояния, обработка ошибок/переподключения.
- [x] Задания и взаимодействия с NPC/козами, камни и словарь, выбор слова из текста.
- [x] Управление блокируется во всех панелях; камера не проходит сквозь окружение.
- [x] `make client-test`, типы/импорты/build, браузерные BABEL S1–S8 с настоящим сервером.
- [ ] LAN/соло с отключённым Wi-Fi и реальная LLM проверены отдельно; автоматические тесты их не заменяют.

## Результат

Подключены BabylonClient и панели BABEL. Транспорт ограничивает ответ, валидирует его, отменяет запросы при выходе, сохраняет requestId для повтора и не применяет старый polling поверх новой команды. Черновик камня сохраняет собственный ID до подтверждения, в том числе после других действий. Все поля остаются текстом.

2026-10-31: `make client-test` — 157/157 в 22 файлах; `npm --prefix client run check` — Svelte 0 ошибок/предупреждений, TS и headless Core; `check:imports` — 92 модуля / 261 зависимость, без нарушений. Браузерные сценарии BABEL проходят с настоящим сервером и тестовым языковым портом. Ошибки/повторы/приватность и режимы 3–4 дополнительно проверены сервисными и HTTP-тестами; S2 покрыт регрессиями камеры/Pointer Lock. Полная LLM-приёмка S3/S6 не заявляется. Реальная модель, четыре физических устройства LAN и выключенный Wi-Fi пока не проверены.
