# Панель администратора: все разделы на готовых серверных API

## Цель и изменения требований
Довести `/operator` до ADMIN-001–028: графики и показатели из истории метрик, FPS клиентов, редактирование NPC и живого мира, журнал, аккаунты. Страница остаётся встроенной в сервер (HTML/CSS/JS без сборки, внешних ресурсов и браузерного хранения). Требования не меняются; закрыты открытые вопросы о стиле «Обзора» и поиске аккаунта, IP в таблице клиентов не показывается до решения.

## Реализация
- [x] Обзор: плитки из `status.overview`, графики «Игроки онлайн» и «Время ответа NPC», таблица игроков с FPS, «Последние события» с уровнями.
- [x] Сервер: карточки шага/рассылки/памяти/ошибок за час, графики «Производительность сервера» и «Память», «Очередь NPC», «NPC за 5 минут», «Диск и база данных», «Ошибки по событиям» (5/60 мин); уровни info/warn/error подписаны правильно.
- [x] Клиенты: FPS, кадр, draw calls, давность отчёта; пороги RTT/FPS/переподключений с подписью; графики ping и FPS по игроку с легендой.
- [x] NPC: плитки, таблица с поиском, картой и удалёнными; редактор по `editable` (embedded — пояснение вместо карты, позиции и облика; quest — предупреждение); создание с обликом из `appearances`; удалить/восстановить/сбросить к исходному с подтверждением; изменения персонажа; блок «Карты и живой мир» со сбросом сцены и списком пропущенных.
- [x] Журнал: фильтры цели, персонажа, действия, периода и поиска; пагинация; детали «было/стало»; экспорт CSV по тем же фильтрам.
- [x] Аккаунты: поиск по части имени, карточка (создан, блокировка до, последний вход, карта), сессии с IP входа, история, действия с подтверждением.
- [x] Графики — SVG без библиотек: пороговый пунктир, разрыв на `null`, `"inf"` на верхней границе с пояснением, подсказка при наведении, «нет данных».
- [x] «Ведущий» → «администратор» в сообщениях `operatorRoutes.ts`.
- [x] Браузерный тест `server/test/operator.browser.mjs` расширен новыми разделами.
