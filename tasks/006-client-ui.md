## Результат
После rebase на d257b02 задача переоткрыта: новые UI-005/NET-004/PROTO-007 требуют NPC streaming, cancel, preferences и чтения durable result. Эти сценарии не реализованы и не засчитаны прежними тестами; нижеследующие результаты относятся к прежнему клиентскому контракту. Решение 2026-10-31 (серверные спеки): PROTO-007 отнесён к PROTO v2; в v1 онлайн-NPC работает через `npc-question`/`npc-answer`, NPC-часть UI-005/NET-004 уточнена. Повторная приёмка по v1 — за клиентской командой; статус без её проверки не меняется.

В прежнем объёме реализованы UI-001–007: физические WASD, Pointer Lock и явный возврат, сброс при blur/visibility/loss, сообщения отказа; главный экран, HUD, загрузка мира, NPC, локальный/сетевой диалог, меню, настройки local/mock/online, адрес/карта/радиус/debug и чат AOI.

Смена настроек завершает прежнюю сессию, canvas/GPU и обработчики, ждёт освобождения старого бюджета. Native dialog ограничивает фокус. Текст выводится через Svelte без HTML; ввод освобождает мышь, блокирует игровые клавиши и оставляет явное продолжение. Чат хранит 50 сообщений, показывает ошибки доставки. NPC-ответы коррелируются с вопросом; тестовый режим явно обозначен.

Проверки 2026-10-31: make client-test — 125/125, check — 0 ошибок/предупреждений, check:imports — без нарушений, production browser — 17/17, render — 4/4. S1–S7 подтверждены маршрутами обоих NPC, вводом/фокусом, захватом/отказом, перезапуском, загрузкой/ошибками карты, сменой сессии/карты, чатом с HTML-подобной строкой, ответом NPC и восстановлением связи. Исправлен доступ к настройкам на экране отказа авторизации.
