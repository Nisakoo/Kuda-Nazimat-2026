# Стиль существующих кнопок и устранение перекрытий

## Область работы

Уточнение пользователя: сохранить текущие состав и поведение интерфейса, изменить стиль и исправить артефакты. Не возвращать отменённые элементы макетов и не добавлять новые действия. Новых требований нет. Ветка `fix/ui-reference-fidelity` от актуального `origin/main`.

## Дизайн по изображениям

Изучены все десять экранных референсов в `specs/images/`: autorize, track, oblik_page, pause, setting, inventar, map, dictionary, chat, chat_resident. Изображения персонажей не являются макетами кнопок.

- Тёплые поверхности пергамента, песочные тонкие границы, тёмный сине-бирюзовый текст, спокойные тени. Сохраняются простые карточки без отменённых орнаментов.
- Главные действия — прямоугольники со скошенными углами, глубокая бирюза с небольшим перепадом света, светлая надпись. Второстепенные — пергамент с песочным контуром и тёмным текстом.
- Иконки закрытия/вращения/пароля и текстовые ссылки имеют прозрачную поверхность; вкладки — бирюзовое подчёркивание без объёмной заливки. Выбранные строки/карточки — мятная поверхность с бирюзовым выделением.
- Состояния hover/active/focus/disabled не двигают элементы. Клавиатурный фокус остаётся видимым внутри скошенного силуэта. Обычные кнопки не ниже 44 px; слова в репликах сохраняют строчное оформление.
- Поля светлые, утопленные; громкость — бирюзовая дорожка и светлый круглый бегунок. Кольцо выносливости 56 px по центру снизу; подсказка NPC и статус рук занимают отдельные ячейки раскладки.
