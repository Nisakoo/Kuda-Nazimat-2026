# Первый этап панели администратора

## Цель и изменения требований
Начать ADMIN на существующем сервере: каркас по макетам, обзор, сервер,
клиенты и уже доступные действия с аккаунтами. Требования не изменяются.
Спека остаётся draft: вопросы хранилища NPC, IP и поиска аккаунтов не решаются этой задачей.

- [x] Общий каркас, навигация, ручное/автоматическое обновление, сохранение последнего снимка при ошибке.
- [x] Обзор и сервер: адреса, места, состояние, доступные текущие метрики и предупреждения.
