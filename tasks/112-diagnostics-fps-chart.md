# График FPS в игровой диагностике

## Цель и изменения требований

По запросу пользователя добавить видимый в игре график frame rate. Добавлено QUALITY-007: график отправленных кадров за последнюю минуту, с ограниченным сбором и сбросом истории. Это дополнение к текущей работе ROPT; TASK-111 продолжает учитывать принятый baseline, но batching ещё не внедрён.

## Реализация

- [x] Ограниченная история фактических отправок: одна точка/секунду, максимум 60.
- [x] Компактный SVG-график в существующей debug-панели, подписи FPS/времени и доступное текстовое описание; без нового цикла рендера.
- [x] Сброс при restart/resume/debug off/visibility; тесты и браузерный кадр.

## Приёмка

- [x] QUALITY S4: график появляется только в диагностике, обновляется и отражает GPU-пропуски; история ограничена и сбрасывается.
- [x] Проверки клиента, типов, импортов, build и относящиеся браузерные/render сценарии проходят; evidence записано.

## Результат

`FrameMetrics` агрегирует реальные submissions за окна ≥1 с и хранит максимум 60 точек последней минуты. Это отдельная краткая история графика, а не сглаженный FPS по последним 600 кадрам текстовой строки. Полный GPU stall даёт точку 0 FPS при продолжающемся цикле. Сбор работает только при debug; AppSnapshot обновляется существующей секундной публикацией, SVG не имеет таймеров/анимаций и доступен через title/aria-label. Сцена/visibility/debug off сбрасывают историю; пустая история не порождает лишних UI-уведомлений.

Проверено на macOS 26.3, Apple M4 / 16 GB, Node 24.22.2, Chrome 156 / WebGL2. Из корня:

- `NODE_OPTIONS=--no-experimental-webstorage make client-test`: **479/479**, 57 файлов (лог (артефакт удалён)); новый unit проверяет 50 FPS при половине отправок, 0 при stall, 60-точечный cap/окно и reset.
- `npm --prefix client run check`: **0 ошибок/предупреждений** (лог (артефакт удалён)).
- `npm --prefix client run check:imports`: **PASS** (лог (артефакт удалён)).
- `npm --prefix client run build`: **PASS**, штатное предупреждение bundle >500 kB (лог (артефакт удалён)).
- Из `client/`: `PLAYWRIGHT_CHANNEL=chrome PLAYWRIGHT_PORT=4199 npx playwright test e2e/graphics.spec.ts -g 'quality profiles|GPU backpressure|FPS chart'`: **3/3 PASS** (лог (артефакт удалён)); три профиля/resize, реальная сцена с графиком, снижение его FPS при GPU-пропусках, visibility handler и выключение диагностики.
- `PLAYWRIGHT_CHANNEL=chrome npm --prefix client run test:render`: **15/15 PASS** (лог (артефакт удалён)).

Кадр интерфейса: game.png (артефакт удалён), CSS 1280×800 / DPR 2. История на нём только начала заполняться справа; полный минутный cap проверен unit-тестом, ускоренная браузерная съёмка за минутный замер не выдаётся. Server/shared и профили качества не менялись. Заметного ускорения от графика не заявляется. Изолированный baseline TASK-110 остаётся архивированным; сравнительные измерения batching используют одинаковую конфигурацию UI между A/B.

Артефакты проверок удалены по запросу пользователя; исторические результаты и команды выше сохранены. Новые материалы проверок хранятся вне checkout (TASK-119).
