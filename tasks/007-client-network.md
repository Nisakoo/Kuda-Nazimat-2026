## Результат
После rebase на d257b02 задача переоткрыта: новые UI-005/NET-004/PROTO-007 требуют NPC streaming, cancel, preferences и чтения durable result. Эти сценарии не реализованы и не засчитаны прежними тестами; нижеследующие результаты относятся к прежнему клиентскому контракту.

В прежнем объёме NET-001–006 реализованы: NetworkAdapter, SocketIOAdapter и MockNetworkAdapter. Socket.IO импортируется только конкретным адаптером; autoConnect/reconnection отключены. Без действующей серверной сессии реальный транспорт не создаётся; mock-контекст защиту не обходит. Есть статусы, timeout 5 секунд, retry 1/2/4 секунды максимум три раза, терминальный отказ авторизации/версии, очистка таймеров/подписок/буферов при logout/dispose.

OnlineSession реализует GameSession поверх Core replica. После join получает playerId/подтверждённую позицию и bootstrap. Последующие снимки/дельты применяются на update; очередь максимум восемь пакетов, overflow/gap вызывает resync, stale revision игнорируется. Ввод — последнее намерение до 20 Hz с preparedChunks, без клиентского присваивания позиции. Нулевой ввод отправляется и при остановленном update. Отдельная история восьми снимков интерполирует удалённые объекты с задержкой 100 ms. Reconnect делает новый join без воспроизведения действий; чат/NPC имеют корреляцию, pending ≤32 и timeout 10 секунд.

GameApp передаёт готовый серверный контекст через provideServerSession сетевому и HTTP-адаптерам; не сохраняет токен в URL/storage. HTTP 401/403/истечение закрывают клиентский обмен. UI показывает ошибки и позволяет вернуться к локальной игре.

Проверки 2026-10-31: make client-test — 125/125, check — 0 ошибок/предупреждений и headless session/Core, check:imports — без нарушений; 17 production browser и 4 WebGL сценария прошли. Unit: auth barrier, ограниченные retry/expiry/dispose, намерения/готовность, два удалённых объекта и отдельная интерполяция, применение на update, stale/gap/overflow/resync, NPC-корреляция/timeout, два клиента чата и отмена при reconnect. GameApp-тест подтверждает старт в сохранённой позиции 100,0,8 вместо spawn 8,0,8. Browser: local→mock, чат/блокировка ввода, разрыв→новый join, NPC, смена карты и local→online без контекста→local.

CLIENT-007/S5 и клиентская CLIENT-012/S9 выполнены. NET-007/S4, реальная проверка токена/отзыва, AUTH и LAN-мультиплеер не проверены: сервера нет. Mock и порт передачи контекста не заменяют TASK-016; NET implementation остаётся partial.
