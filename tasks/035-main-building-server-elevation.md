# Серверная высота наружной лестницы

## Цель

Добавить в общий формат manifest ограниченные непересекающиеся поверхности высоты: линейный пандус и горизонтальная площадка. Сервер вычисляет Y по XZ и запрещает скачок выше 0,35 м за шаг; клиент не назначает высоту. Клиентское локальное движение и визуализация выполняются отдельно в TASK-034.

## Приёмка

- [x] Общий парсер отклоняет некорректные, пересекающиеся и слишком крутые поверхности.
- [x] Сервер поднимает игрока на 3 м по лестнице и возвращает на землю, боковой скачок запрещён.
- [x] Серверные тесты, типы и границы импортов проходят.

## Результат
